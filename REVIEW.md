# Website review

Operator-focused landing page for Ekonomy AI and ProvisionOS, built with Next.js, TypeScript, and static export.

## Design

The public Navigate.ai site informed the page hierarchy, oversized typography, generous spacing, and contrasting sections. Its assets, customer logos, testimonials, and claims are not reused. Product illustrations and workflows are explicitly concepts, not live product screenshots.

## Local verification

Run `npm ci`, `npm test`, `npm run lint`, `npm run typecheck`, and `npm run build` where available in this revision. The build writes static output to `docs/`; this source-review branch does not update committed deployment output.

Review responsive layouts, keyboard interactions, copy feedback, and contrast before release. Component tests do not replace browser accessibility testing.

## Scope

This is a source review, not a deployment. The pilot planner is a local-only discussion aid: no signup, storage, booking, or network submission. A real contact destination, dependency advisory assessment, and review of inherited public assets/generated output remain release follow-ups.
